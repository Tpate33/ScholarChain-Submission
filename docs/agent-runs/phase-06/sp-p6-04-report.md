## Design (key fields)

- Store abstraction `scholarchain.spark.store`: `StorePath` (scheme, authority, segments; strict parse) and `RunStore` (stat, list, open, createNew, deleteRecursively) with `NioRunStore` (unchanged local guarantees: NOFOLLOW_LINKS, CREATE_NEW) and `HadoopRunStore(conf)` (FileSystem per URI; ChecksumFileSystem unwrapped). Reader (RunTree, CuratedParts, HadoopCuratedRun, VerifiedArchiveReader) and publishers (RunPublisher, LoadManifests) run over a store; old Path overloads kept.
- Commit-marker protocol on Hadoop stores (no rename, no conditional put): refuse if `run=<hex>` or `.spark-<hex>` exists; Spark executors write into `.spark-<hex>/`; driver lists through the output FileSystem and checks schema/rows; each part copied create-once into `run=<hex>/` with hash-while-copy and re-read verification; `_run-manifest.json`, `_parts.json`, full byte verification, then `_SUCCESS` last (commit point), re-verify, delete scratch. Load manifests: `load=<hex>/` refused if present, four files create-once and verified. Nothing is ever deleted under `run=` or `load=`. Partial runs (no `_SUCCESS`, or `_UNVERIFIED`) are refused by both readers and cannot be re-published; remedy is attempt + 1 or human removal.
- Atomicity: local whole run atomic (rename); HDFS and S3A per file/object only, run completion = `_SUCCESS`; create-once on S3A is check-then-put (single-writer assumption load-bearing).
- Entry point `scholarchain.spark.job.CollaborationJob`, 17 required flags: `--input-root`, `--curated-run`, `--decision-run`, `--grouping-run`, `--output-root`, `--checkpoint-dir`, `--config`, `--benchmark-pairs`, `--code-version` (40 hex; all-zero and `unpinned-sparkit-dev` refused), `--attempt`, `--partitions`, `--checkpoint-interval`, `--max-tree-entries`, `--max-tree-depth`, `--max-driver-validation-rows`, `--max-driver-validation-bytes`, `--max-metadata-bytes`. Refuses `s3:`/`s3n:`, overlapping roots, `file:` roots under a non-local master. Exit 0 published and verified, 2 arguments refused (no SparkSession), 1 other refusal. No master set in code; config resolved with an empty environment.
- Event log: no code change (spark-submit `--conf spark.eventLog.*`; local/HDFS then copy preferred over direct S3A).
